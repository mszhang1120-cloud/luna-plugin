# /risk-score — 위험도 평가 커맨드

대상 `git diff`를 5축으로 채점 (높을수록 위험):

| 축 | 배점 | 설명 |
|----|------|------|
| Security | 30 | 시크릿 노출, 인증/인가 우회, SQL 인젝션 등 |
| Scope | 20 | 변경 파일 수, 영향 범위, 핵심 모듈 침범 |
| Breaking | 20 | 인터페이스 변경, 마이그레이션 필요, 호환성 파괴 |
| Tests | 15 | 테스트 부재, 커버리지 감소, 플래키 테스트 |
| Migration | 15 | DB 스키마 변경, 설정 변경, 배포 복잡도 |

각 축 점수 근거 한 줄씩. 총점으로 등급:
- 🟢 0~15: 셀프 머지 가능
- 🟡 16~35: 동료 1명 리뷰 필수
- 🟠 36~60: 시니어/아키텍트 리뷰 + Security/Arch 추가 검토
- 🔴 61+: 머지 보류, 설계 논의(RFC/ADR) 필요

출력: 축별 표 + 총점 + 등급 + 권장 액션.
